# 🎚️ 3-Channel Analog Audio Mixer with 3-Band Equalizer  

## 📌 Project Overview  

This project presents the design and implementation of a **3-Channel Analog Audio Mixer** with independent **3-band equalization per channel**, developed as part of Semester 3 coursework.

The system integrates:

- 🎛️ Three independent audio input channels  
- 🎚️ 3-band Equalizer (Bass, Mid, Treble) on each channel  
- 🔊 Analog summing mixer stage  
- 🔌 Regulated power supply  
- 🖥️ Custom PCB designed in Altium  
- 🧱 Custom enclosure designed in SolidWorks  

This project focuses on analog circuit design principles, PCB layout practices, and mechanical enclosure development for a complete hardware solution.

---

## ⚙️ Features  

- ✔ 3 Independent Audio Inputs  
- ✔ Individual Gain Control per Channel  
- ✔ 3-Band Equalizer (Low / Mid / High) for each channel  
- ✔ Analog Summing Amplifier  
- ✔ Low-Noise Analog Design
- ✔ Professionally Designed PCB

## 🏗️ System Architecture  

### 1️⃣ Input Stage  
Each channel includes:
- Input coupling capacitor  
- Gain control potentiometer  

### 2️⃣ Equalizer Stage  
Each channel implements a **3-Band Active Equalizer**:
- 🎵 Bass Control  
- 🎶 Mid Control  
- 🎼 Treble Control  

Active filter circuits were designed using analog ICs (op-amps), while part of the signal conditioning circuitry was custom designed using analog electronics principles.

### 3️⃣ Mixer Stage  
- Analog summing amplifier
- Master volume control  

### 4️⃣ Power Supply  
- AC to DC conversion  
- Rectifier and filtering stage  
- Voltage regulation  
- Dual supply rails for op-amp operation (±V)
